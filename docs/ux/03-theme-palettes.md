# 마이키티 — 작품 테마 팔레트 v0.1

> 월드(S3)·홈 헤더(S2)·도감 링(S5)·공유 카드(S8)의 색은 전부 여기서 나온다.
> 규칙: 작품마다 **주색 1 + 보조색 1**. 그 외는 공통 토큰을 쓴다.

## 공통 토큰 (모든 월드 동일)

| 토큰 | 값 | 용도 |
|---|---|---|
| `--bg` | `#0d0d0f` | 화면 배경 |
| `--panel` | `#17171a` | 패널·카드 |
| `--line` | `#333333` | 테두리 |
| `--fg` | `#f2f0ea` | 본문 글자, **붓칠 기본색(종이)** |
| `--muted` | `#8e8b84` | 보조 글자 |
| `--cta` | `#e5322d` | **쿠팡 CTA 전용**. 어떤 월드에서도 바뀌지 않음 |

## 작품별 토큰

| 작품 | `--theme` 주색 | `--theme2` 보조색 | 헤더 그라데이션 | 메모 |
|---|---|---|---|---|
| **귀멸의 칼날** | `#2fd36f` 초록 | `#ff7a1a` 주황 | 초록 40% → bg | 탄지로 하오리 + 렌고쿠 불꽃. 기준 팔레트 |
| **주술회전** | `#4f6df5` 남청 | `#b06cff` 보라 | 남청 40% → bg | 고죠 육안 파랑 + 영역전개 보라. 차갑고 날카롭게 |
| **체인소맨** | `#ff6a00` 주황 | `#f2f0ea` 종이 | 주황 45% → bg | 체인소 주황 + 종이색 잉크 튐. 붓칠을 가장 거칠게 써도 되는 월드 |
| **원피스** | `#ffcc33` 밀짚 노랑 | `#2eb3ff` 바다 파랑 | 노랑 35% → bg | 빨강은 쿠팡 CTA와 겹쳐 **보조색에서 제외**. 밀짚모자 + 바다 |
| **장송의 프리렌** | `#c9b6ff` 연보라 | `#f2f0ea` 종이 | 연보라 30% → bg | 가장 밝고 잔잔한 월드. 잉크 튐 대신 **작은 점(꽃잎)** 1~2개 |
| **스파이 패밀리** | `#1fb27a` 초록 | `#ff8fb1` 아냐 분홍 | 초록 40% → bg | 로이드 정장 초록 + 아냐 머리 분홍. 빨강은 CTA와 겹쳐 제외 |

## 적용 규칙

1. **주색(`--theme`)**: 헤더 그라데이션, 선택 상태(칩·타일 테두리), 도감 링, 완성도 숫자, 레벨 숫자, 테마 CTA(온보딩 "다음", 공유 "공유").
2. **보조색(`--theme2`)**: 잉크 튐, 재입고 스탬프, 캐릭터 링 강조 1개, 공유 카드 배경 옵션 2번.
3. **붓칠 색**: 기본은 종이(`--fg`). 강조가 더 필요할 때만 주색. 보조색 붓칠은 쓰지 않는다(튐과 역할 분리).
4. **쿠팡 CTA**: 항상 `--cta` 빨강. 월드 색이 빨강 계열이면 보조색을 바꿔서라도 CTA와 구분한다 → 원피스·스파이 패밀리가 이 규칙으로 보조색을 조정했다.
5. **대비**: 주색 위에 올라가는 글자는 `#000`(귀멸·체인소맨·원피스·프리렌·스파이) 또는 `#fff`(주술회전). 밝은 주색은 검정 글자, 어두운 주색은 흰 글자.
6. **헤더 그라데이션 세기**: 밝은 주색(노랑·연보라)은 30~35%, 어두운 주색(남청)은 40%, 채도 높은 주색(주황)은 45%. 눈으로 맞춘 값이라 실제 화면에서 재조정.

## 월드가 늘어날 때

새 작품을 추가할 때는 ① 주색 1 + 보조색 1만 정하고, ② 빨강 계열이면 CTA 규칙 확인, ③ 글자색 흑/백 결정, ④ 그라데이션 세기 30~45% 중 선택. 이 네 가지면 끝.
