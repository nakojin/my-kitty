# 마이키티 — 화면 목록과 사용자 흐름 (초안 v0.1)

> 상태: 구도 잡기 단계. 레퍼런스(Mobbin)는 다음 세션에서 화면별로 붙인다.

## 1. 서비스 한 줄 정의

**"애니 피규어를 도감처럼 모으고, 추천받고, 쿠팡에서 산다."**

- 사용자 가치: 뭘 사야 할지 모르는 입문자에게 작품별로 실패 없는 선택지를 주고, 모은 피규어를 도감으로 기록하게 한다.
- 수익 모델: 모든 상품 카드 → 쿠팡 파트너스 링크. 도감·퀘스트는 재방문과 구매 전환을 끌어올리는 장치.
- 플랫폼: 모바일 우선 반응형 웹 (PWA). 데스크톱은 2열 레이아웃으로 확장.

## 2. 디자인 방향 — 게임성 × 애니메이션

| 게임 장치 | 서비스에서의 모습 | 왜 넣는가 |
|---|---|---|
| **도감(Pokédex)** | 작품별 피규어 도감. 보유/위시/미보유 3상태, 완성도 % | 핵심 재방문 동기. "빈칸 채우기" 욕구 |
| **월드맵** | 홈에서 작품별 "월드"로 진입. 월드마다 작품 색·분위기 | 작품 팬덤별 몰입. 탐색이 지루하지 않음 |
| **뽑기 연출** | "오늘의 추천 뽑기" — 카드 뒤집기 애니메이션으로 피규어 1개 공개 | 매일 들어올 이유. **실제 과금·확률 없음**, 추천 연출일 뿐 |
| **레어리티** | 프라이즈 = 일반, POP UP PARADE = 레어, 스케일 = 에픽, 한정판 = 전설 | 가격대를 게임 언어로 번역. 입문자가 등급을 직관적으로 이해 |
| **퀘스트·뱃지** | 데일리 체크인, 첫 도감 등록, 작품 완주, 득템 인증 | 행동 유도. 뱃지는 공유 카드에 노출 |
| **레벨** | 도감 등록·퀘스트로 경험치. 레벨은 프로필·공유 카드에 표시 | 누적감. 랭킹은 MVP에서 제외(비교 피로) |

**애니메이션 톤**
- 화면 전환: 월드 진입 시 작품 테마 색으로 와이프. 상세 진입은 카드 확대(shared element).
- 마이크로 인터랙션: 도감 등록 시 카드가 "꽂히는" 모션 + 완성도 게이지 상승. 뱃지 획득은 짧은 팝업(2초 이내).
- 금지: 자동 재생 사운드, 3초 넘는 강제 연출, 광고성 팝업. 쿠팡 버튼은 어디서나 **연출 없이 즉시** 동작.

**레이아웃 원칙**
- 하단 탭 4개: 홈 · 탐색 · 도감 · 마이. 쿠팡 버튼은 상세 화면 하단 고정.
- 모든 상품 카드는 같은 구조: 썸네일 / 이름 / 레어리티 / 가격대 / 도감 상태 / 쿠팡 버튼.
- 파트너스 고지 문구는 모든 화면 하단에 고정(규정).

## 3. 화면 목록

### MVP (1차)

| # | 화면 | 핵심 요소 | 주요 액션 |
|---|---|---|---|
| S1 | **스플래시·온보딩** | 서비스 한 줄 소개, 좋아하는 작품 3개 고르기(타일), 닉네임 | 취향 저장 → 홈 |
| S2 | **홈** | 오늘의 뽑기 카드, 데일리 체크인, 내 월드(선택 작품) 바로가기, 신상·재입고 피드 | 뽑기 / 월드 진입 / 상세 |
| S3 | **작품 월드** | 작품 테마 헤더, 큐레이션(TOP 5 글), 캐릭터 타일, 레어리티·가격 필터, 도감 완성도 | 상세 / 필터 / 도감 |
| S4 | **피규어 상세** | 사진(쿠팡 제공), 이름·제조사·라인·스케일, 레어리티, 가격대, 정품 체크포인트, 추천 이유 | **쿠팡 버튼(고정)** / 도감 담기(보유·위시) / 공유 |
| S5 | **도감** | 작품별 탭, 3상태 그리드, 완성도 %, 레어리티별 집계 | 상태 변경 / 상세 / 공유 카드 |
| S6 | **탐색·검색** | 검색창, 작품·캐릭터·라인·가격대 필터, 결과 그리드 | 상세 |
| S7 | **마이** | 레벨·경험치, 뱃지, 퀘스트 목록, 설정(알림·테마), 제휴 고지·소개 | 퀘스트 확인 / 설정 |
| S8 | **공유 카드** | 도감 완성도·뱃지·대표 피규어를 담은 이미지. 작품 테마 배경 | 이미지 저장 / 링크 복사 |

## 4. 사용자 흐름

### F1. 첫 방문 → 첫 구매 (가장 중요)

```
S1 온보딩 ─ 작품 3개 선택 ─→ S2 홈
                                │
                     "오늘의 뽑기" 카드 뒤집기
                                │
                                ▼
                         S4 피규어 상세 ──→ 쿠팡(새 탭) ──→ 복귀
                                │                              │
                           도감 담기(위시)                  "득템했나요?" 토스트
                                │                              │
                                ▼                              ▼
                         S5 도감 (완성도 ↑)            보유로 전환 + 뱃지
```

- 온보딩은 **3탭 이내**. 작품 선택이 곧 "내 월드" 생성.
- 뽑기 결과는 선택 작품에서만 나온다. 첫 뽑기는 2~3만 원대 입문 피규어로 고정(전환 확률).
- 쿠팡은 새 탭. 복귀 시 "득템했나요?" 한 번만 묻고, 아니면 조용히 넘어간다.

### F2. 재방문 (데일리 루프)

```
S2 홈 ─ 데일리 체크인(경험치) ─ 오늘의 뽑기 ─→ S4 상세 ─→ 위시/쿠팡
   │
   └─ 신상·재입고 피드 ─→ S4 상세
   │
   └─ 내 월드 ─→ S3 작품 월드 ─ 빈칸 확인 ─→ S4 상세
```

- 하루에 뽑기 1회. 체크인·뽑기 둘 다 10초 안에 끝나야 한다.
- 피드는 "재입고"를 최상단에. 품절 경험이 있는 피규어 팬에게 가장 강한 훅.

### F3. 탐색 → 구매

```
S6 탐색 ─ 검색어 or 필터 ─→ 결과 그리드 ─→ S4 상세 ─→ 쿠팡
                                              │
                                         같은 라인 추천 (크기 통일 유도)
```

- 상세 하단에 "같은 라인 다른 캐릭터"를 보여 세트 구매를 유도한다. (원피스 글의 '크기 통일' 조언을 UI로 옮긴 것)

### F4. 도감 → 공유 (바이럴)

```
S5 도감 ─ 작품 탭 ─ 완성도 확인 ─→ S8 공유 카드 생성 ─→ 저장/링크
                                          │
                                   링크 열람자 → S1 온보딩
```

- 공유 카드에 서비스 링크를 넣어 신규 유입 경로로 삼는다.
- 공유 카드 디자인은 작품 테마를 따르되, 쿠팡 고지는 카드가 아닌 랜딩 페이지에.

### F5. 퀘스트 → 뱃지

```
행동(체크인/도감 등록/작품 완주/득템) ─→ 경험치 ─→ 레벨업 팝업(2초)
                                          │
                                     조건 달성 시 뱃지 ─→ S7 마이 / S8 공유 카드
```

## 5. 정보 구조 (하단 탭)

```
홈(S2)         탐색(S6)        도감(S5)        마이(S7)
 ├ 뽑기         ├ 검색           ├ 작품별 탭      ├ 레벨·뱃지
 ├ 체크인       ├ 필터           ├ 완성도         ├ 퀘스트
 ├ 내 월드 → S3 └ 결과 → S4     └ 공유 → S8      ├ 설정
 └ 피드 → S4                                     └ 소개·제휴 고지
```

S4(상세)는 어느 탭에서든 모달/푸시로 열리며, 하단에 쿠팡 버튼이 고정된다.

## 6. 지켜야 할 제약

- **쿠팡 파트너스**: 고지 문구 모든 화면 노출. 상품 이미지는 쿠팡 제공 이미지만 사용(AI 생성 금지). 가격은 "대략적 시세"로 표기하고 실제 가격은 쿠팡에서 확인하도록 안내.
- **게임성의 선**: 실제 과금 뽑기·확률 아이템 없음. 뽑기는 "추천 연출"이며 결과는 항상 실제 상품. 랭킹·경쟁 요소는 MVP 제외.
- **성능**: 연출은 CSS/Lottie 수준. 첫 로딩 3초 이내, 쿠팡 버튼은 연출과 무관하게 즉시 반응.
- **데이터**: MVP는 로그인 없이 기기 저장(localStorage)으로 시작 → 공유·알림 단계에서 계정 도입.

## 8. 열린 질문

1. 온보딩에서 고르는 작품은 **3개 고정**인가, 1~5개 자유인가?
2. "득템 인증"(S9)을 MVP에 넣을지 — 넣으면 도감 보유 상태의 신뢰도가 올라가지만 사진 업로드·검수 비용이 생긴다.
3. 다크 모드를 기본으로 갈지(애니·게임 톤에 유리) 라이트 기본인지.
4. 서비스 이름을 "마이키티"로 유지할지.
