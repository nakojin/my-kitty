# 마이키티 — 이미지 브리프 (아르 / ChatGPT 작업용)

> 프로토타입의 빗금 자리마다 **슬롯 ID**가 적혀 있다. 아래 브리프로 이미지를 만들고, 같은 ID의 파일명으로 `public/proto/img/`에 넣으면 된다 (예: `IMG-W01-HERO.webp`).
> 공통 톤: **다크 배경 · 거친 붓칠 · 잉크 튐 · 스트리트파이터 V식 그라피티 질감 · 종이(#f2f0ea) 하이라이트**. AI 느낌이 나지 않도록 **디지털 페인팅/실크스크린 포스터 질감**을 요청한다.

## ⚠️ 먼저 — 만들면 안 되는 것

1. **실제 피규어 상품 이미지**(`COUPANG-*` 슬롯) — 쿠팡 제공 이미지만 사용. AI 이미지로 상품을 대신하면 파트너스 규정 위반 + 구매자 오해.
2. **원작 캐릭터를 그대로 그린 그림** — 탄지로·고죠 등 실제 캐릭터 얼굴/복장을 재현한 이미지는 저작권 문제. 월드 히어로는 **작품을 연상시키는 추상·오브제·색·질감**으로만.
3. 사진처럼 보이는 실사 인물.

## 작업 순서 제안

1. **A 월드 히어로 6장**(W01~W06) — 지금 글이 있는 작품부터. 화면 인상이 가장 크게 바뀐다.
2. **B 랭킹 헤더 2장**
3. **F OG 1장**, **D 아바타 1장**
4. C, E는 여유 있을 때

## 파일 규격

- 포맷: WebP (품질 80) 또는 PNG. 히어로는 400KB 이하.
- 파일명 = 슬롯 ID. 예: `public/proto/img/IMG-W01-HERO.webp`
- 파일을 `public/proto/img/`에 넣고 커밋하면 **자동으로 채워진다**. 파일이 없는 슬롯은 지금처럼 빗금 자리표시자로 남는다.
