아트 디렉션 메모 — ① 붓칠은 강조 1곳에만(제목 핵심어, 완성도 숫자). 모든 곳에 쓰면 싸 보인다. ② 스큐 각도는 패널 −6°, 칩·CTA −8°, 붓칠 −10~−20°로 통일. ③ 잉크 튐은 화면당 1~3개, 테마 보조색 또는 종이색. ④ 쿠팡 CTA는 붓칠 없이 빨강 스큐 블록만 — 연출과 분리. ⑤ 실제 제작 시 붓칠·튐은 SVG 에셋(일러스트레이터 작업)으로 교체하고, 지금은 CSS 필터로 자리만 잡았다.
