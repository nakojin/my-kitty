# My Kitty 테마 — 설치 후 QA 체크리스트 (5단계)

> 이 저장소 환경에는 워드프레스가 없어 **실제 활성화 테스트를 하지 못했다.** 설치 후 아래 순서대로 확인하고, 깨지는 항목은 이슈로 남긴다.

## 0. 설치
- [ ] `wp-theme/mykitty` 업로드·활성화 → 관리자 메뉴에 **피규어**, **랭킹 항목** 생김
- [ ] 설정 → 고유주소 "글 이름" 저장
- [ ] `wp eval-file wp-theme/import/import.php` → worlds 9 / figures 107 / rankings 110 / posts 6 성공 메시지
- [ ] 설정 → 읽기: 홈 = "홈" 페이지, 글 페이지 = "피규어 추천 글" (활성화 시 자동 설정됨)

## 1. 뼈대
- [ ] 홈 상단에 폰 프레임(390px)·하단 탭바·고지 문구 보임. 모바일에서는 풀스크린
- [ ] 관리자 바가 있어도 프레임이 가려지지 않음
- [ ] 소스에 `<filter id="rough">` 1개, `MK_WORLDS` 9개, `MK_FIGURES` 107개

## 2. 월드 + 상세
- [ ] `/world/kny/` 헤더가 초록 그라데이션, `/world/jjk/` 는 남청. 도감 % 표시
- [ ] 탭 큐레이션/캐릭터/전체 전환. 캐릭터 링 탭 → 전체 탭에 캐릭터 필터
- [ ] 피규어 카드 탭 → **바텀시트**가 올라오고 URL 이 `/figure/kny-01/` 로 바뀜. 뒤로가기 → 시트 닫힘
- [ ] 시트에서 "도감 담기" → 위시 → 보유 → 해제 순환, 토스트, 카드 테두리 즉시 변경
- [ ] `/figure/kny-01/` 직접 접근 → 전체 페이지. 하단 CTA 고정
- [ ] 쿠팡 링크 없는 피규어 = "쿠팡 링크 준비 중". 있는 피규어 = 빨간 CTA, `rel="sponsored nofollow noopener"`

## 3. 홈 + 도감 + 마이
- [ ] 첫 방문 → `/onboarding/` 으로 이동. 3개 미만이면 "다음" 비활성. 5개 초과 시 토스트
- [ ] 다음 → 홈. 스트릭 1일째, 체크인 칩 "오늘 완료 ✓", LEVEL 1
- [ ] 뽑기 "탭해서 공개" → 카드 뒤집힘 → 시트 열림. 새로고침해도 뽑기 결과 유지, 하루 1회
- [ ] 내 월드 타일에 고른 작품만, 각각 도감 %
- [ ] `/collection/` 월드 칩이 고른 작품만. 필터 전체/보유/위시/미보유. 링 % 와 집계 숫자
- [ ] `/my/` 레벨·XP바·3지표·뱃지(획득 = 테마 그라데이션)·퀘스트 체크
- [ ] 로그인 상태에서 도감 변경 → 다른 브라우저에서 로그인 → 상태 동일 (`/wp-json/mk/v1/state`)
- [ ] "데이터 초기화" → 온보딩으로

## 4. 랭킹 + 온보딩 + 공유
- [ ] `/ranking/newera-kr/` 20행, 1~3위 번호 초록. 지역 칩 이동. `/ranking/legend/` 30행, 연대 칩 `?decade=90s`
- [ ] "월드 ›" 있는 행 탭 → 해당 월드
- [ ] `/share/` 카드가 대표 월드 색. 배경 4종 전환. "이미지 저장" → PNG 다운로드(1080×1920). "공유" → 모바일 공유 시트
- [ ] 홈·도감·마이·온보딩·공유 페이지 `<meta name="robots" content="noindex">`

## 5. 콘텐츠·SEO·배포
- [ ] `/posts/` 글 6편. 글 열면 월드 테마 헤더 + 상품 블록 5개 + 하단 "월드 도감 열기"
- [ ] 월드 큐레이션 탭에 해당 글 패널 보임 (curation_post 연결)
- [ ] `view-source:` 에 og:title / og:description / canonical. 월드 페이지 `<title>` = "귀멸의 칼날 피규어 도감 – 사이트명"
- [ ] `/wp-sitemap.xml` 에 figure·world·ranking_board 포함
- [ ] 캐시 플러그인: `?partial=1` 요청이 별도 캐시 키인지 (query_vars 에 등록됨). 로그인 사용자는 캐시 제외 권장
- [ ] 이미지: `assets/img/IMG-W01-HERO.webp` 넣으면 월드 헤더·온보딩 타일·홈에 즉시 반영
- [ ] GitHub Pages 블로그(`nakojin.github.io/my-kitty`) → 워드프레스 주소로 안내 배너 또는 리다이렉트 (Astro `Base.astro` 에 링크 한 줄 추가)

## 알려진 제한
- 공유 카드 PNG 에는 상품 이미지가 들어가지 않는다 (쿠팡 이미지 CORS). 텍스트·도형만.
- 비로그인 상태는 기기(localStorage)에만 저장된다. 브라우저 데이터 삭제 시 초기화.
- 랭킹은 편집부 선정. 분기마다 `public/proto/data/rankings.js` → `node wp-theme/import/build.mjs` → `import.php` 재실행으로 갱신.
